# Open on startup

KOReader decides what to show when it starts: the file browser, the last book you read, and so on. Bookshelf adds itself to that list.

<div class="walk" markdown>

<div markdown>

1. Tap the **top edge of the screen** to open KOReader's menu.
2. Tap the **first tab**, the filing-cabinet icon.
3. Tap the last row, **Start with**.
4. Choose **bookshelf**.

!shot start-with-menu | Start with, in the first tab

The menu closes and your shelf opens. From now on KOReader starts on it.

</div>

!clip startup | KOReader's menu > first tab > Start with > bookshelf.

</div>

!!! note "Can't find Start with?"
    **Start with** is only in the menu while you're on the shelf or KOReader's file browser, not while a book is open. Close the book first, then open the menu.

## Getting back to the shelf

- **From a book**, use KOReader's usual way back to the file browser: the folder icon in the reader's top menu, or a gesture you've set for it. You land back on your shelf, straight away.
- **From KOReader's file browser**, open the menu and choose **Bookshelf > Open Bookshelf**.
- **From anywhere**, you can give it a gesture. In KOReader's menu, under the gear tab, **Taps and gestures > Gesture manager** has an action called **Bookshelf: go to home screen**. Set it on a corner tap, say.

## Turning it off

Choose a different **Start with** option, such as **file browser**. Bookshelf closes at once and KOReader starts as it used to.
